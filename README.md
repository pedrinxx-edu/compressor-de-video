# Compressor de vídeo

Escolhe um vídeo numa janela e gera uma cópia bem menor (até 720p, H.264 + AAC), boa para mandar por e-mail ou chat.

```bash
# precisa do ffmpeg instalado
python main.py
```
Mostra o tamanho antes e depois. O arquivo novo sai na mesma pasta, com `_comprimido` no nome.

Feito por Pedro Costa ([@pedrinxx-edu](https://github.com/pedrinxx-edu)).
